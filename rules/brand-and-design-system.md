# Brand and Design System Guidelines

**Scope**: All UI components, page layouts, marketing sections, typography, and styling.

---

## 1. Brand Aesthetic & Positioning

SlideBee is a premier high-stakes presentation design agency. The design language must convey authority, enterprise polish, clarity, and bespoke craftsmanship. Avoid generic template appearances or cartoonish visual clutter.

---

## 2. Core Color Palette

| Token / Color | Hex Code | Purpose |
| :--- | :--- | :--- |
| **Warm Milk Cream** | `#FFF9E8` | Primary light background, section fills, and light surfaces |
| **Honey Gold** | `#FCBF14` | Accent highlights, interactive hover states, primary CTA buttons |
| **Primary Amber** | `#D99B00` | Secondary accent, border accents, and high-contrast text accents |
| **Deep Charcoal / Black** | `#111111` | Primary typography, headers, dark cards, footer, high-contrast UI |
| **Muted Slate / Gray** | `#726F6D` | Subheadings, secondary captions, metadata labels, borders |
| **Border Neutral** | `#111111/10` | Subtle hairline dividers, card outlines |

---

## 3. Typography Rules

- **Headings**: `Syne` or `Montserrat` font family. Bold to extra-bold weights (`font-extrabold`, `font-black`). Tight letter spacing (`tracking-tight`).
- **Body & Captions**: `Inter` or system sans-serif. Highly legible, relaxed line-height (`leading-relaxed`).
- **Pills & Badges**: Uppercase, tracked-wide (`tracking-widest`, `text-[10px]` or `text-xs`).

---

## 4. Component Patterns

- **Hexagon Geometry**: Utilize hexagon badges (`hex-pill`, `hex-badge`, `hex-card-lg`) to reinforce the hive and bee motif subtly without distracting from content.
- **Glassmorphism & Shadows**: Soft drop shadows (`shadow-sm`, `shadow-md`), subtle backdrop blurs, and hairline borders.
- **Responsive Layout**: Mobile-first grid systems. Ensure tables, marquees, and before/after sliders gracefully collapse on mobile screens.
