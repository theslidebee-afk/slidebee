# Workflow: Code Implementation

Follow this procedure when modifying files:

```text
1. Minimal Coherent Edits:
   - Make the smallest changes that completely satisfy the requirement.
   - Use replace_file_content for targeted edits on existing files.
   - Use write_to_file for new files or complete overwrites.

2. Follow Established Patterns:
   - Match existing component patterns, naming conventions, and Tailwind utility classes.
   - Strictly preserve existing comments, docstrings, and type definitions.

3. Avoid Unrelated Refactoring:
   - Do not refactor adjacent files or functions unless required for the task.
   - Maintain focus exclusively on requested scope.

4. Enforce No-Emojis Directives:
   - Use Lucide React icons for all visual accents.
   - Keep commit messages, text strings, and comments free of unicode emojis.
```
